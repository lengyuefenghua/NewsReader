# NewsReader

## 简要介绍

`NewsReader` 是一款本地优先的 Android RSS 阅读器，支持订阅管理、文章阅读、正文提取和离线查看。

## 技术栈

- Kotlin
- Jetpack Compose
- Room
- OkHttp
- Jsoup

## 软件功能

- 聚合多个订阅源内容，按时间线阅读文章
- 支持未读、已读、全部筛选
- 支持手动添加、编辑、导入导出订阅源
- 内置发现页，可从多个订阅市场查找并预览订阅源
- 支持正文模式、网页模式、收藏和阅读统计
- 支持备份与恢复订阅源、文章和设置

## 如何安装

1. 打开仓库的 Releases 页面。
2. 下载最新版本的 APK 安装包。
3. 在 Android 设备上允许安装未知来源应用后完成安装。

系统要求：Android 9 及以上。
